# SARAS — The Windows Dictionary App

SARAS is a lightweight native Windows desktop app that instantly shows the meaning of any word you double-click, anywhere on your screen — in any app, browser, or document.

## Features
- Instant word lookup on double-click
- Works completely offline after activation
- Optional Wikipedia lookup
- One purchase, one device, no subscriptions
